# Octarine

A horizon-oriented task management application based on the timestripe method.

Octarine helps you organize tasks across five time horizons (Today, Week, Month, Year, No Date) with a focus on recursive subtasks and adaptive interface that works equally well on desktop, tablet, and mobile devices.

## Features

- **Five time horizons**: Today, Week, Month, Year, No Date
- **Recursive subtasks** with automatic completion propagation to parent tasks
- **Adaptive interface**:
  - Columns layout on desktop and landscape tablets/phones
  - Rows layout on portrait mobile devices
  - Automatic switching based on screen orientation (no restart required)
- **Rich text descriptions** with Markdown support (TipTap editor)
- **Local-first storage** using browser localStorage
- **Cross-platform builds**: Android APK, macOS DMG, web

## Quick Start

```bash
# Install dependencies
npm install

# Run development server (web)
npm run dev

# Build all platforms (Android APK + macOS DMG)
./build.sh
```

## Project Structure

```

├── src/                  # React application source code
│   ├── App.tsx           # Main component with adaptive layout

│   ├── storage.ts        # localStorage wrapper (key: 'octarine-tasks')
│   └── ...

├── package.json          # Dependencies and scripts

## Build Outputs

After running `./build.sh`:
- **Android APK**: `android/app/build/outputs/apk/debug/app-debug.apk`
- **macOS DMG**: `dist/Octarine-0.2.0.dmg`

## Development Notes

- **Do not edit** `android/app/capacitor.build.gradle` — it's auto-generated by `npx cap sync`.
- **Always run** `npx cap sync android` after changing web code before building APK.
- **See** [docs/DECISIONS.md](docs/DECISIONS.md) for architectural choices and [ROADMAP.md](ROADMAP.md) for planned features.
