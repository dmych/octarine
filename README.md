# Octarine

A horizon-oriented task management application.

## Features

- Time horizons: Today, Week, Month, Year, No Date
- Recursive subtasks with automatic completion propagation
- Adaptive interface: columns on desktop/landscape, rows on mobile/portrait
- Rich text descriptions with Markdown support
- Local-first storage with optional sync (planned)

## Development

Built with:
- React + TypeScript
- Vite
- Capacitor (for mobile/desktop builds)
